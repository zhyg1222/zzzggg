# 开源视频工具与工作流库

> 收集市面优质的开源视频生成工具、数字人框架、工作流架构，供视频组逆向学习和接线使用。
> 原则：能用开源就不自己造轮子，每个工具都标注来源、能力、接入方式。

---

## 一、视频生成主框架

### 1. ComfyUI（核心框架）
- **来源**：https://www.comfy.org/
- **类型**：开源节点式AI图像/视频生成框架
- **能力**：
  - 节点式工作流，可视化连接每个生成步骤
  - 支持Stable Diffusion、FLUX、WAN、HappyHorse等多模型
  - 工作流保存为JSON，可版本化、协作、复现
  - 支持T2V（文生视频）、I2V（图生视频）、R2V（参考生视频）
  - 支持4K分辨率、音频同步生成（FLUX 3）
- **接入方式**：本地部署，API调用，或作为ComfyUI节点接入现有工作流
- **为什么选它**：市面最成熟的节点式视频生成框架，生态最丰富，工作流可复用
- **对标我们的差距**：我们的视频生成是线性的，没有节点式工作流，不可视化、不可复用

### 2. AnimateDiff
- **来源**：https://github.com/continue-revolution/sd-webui-animatediff
- **类型**：Stable Diffusion动画扩展
- **能力**：
  - 给任何SD模型加运动模块，生成动画
  - 支持motion-LoRA、上下文窗口选项
  - ComfyUI版本：ComfyUI-AnimateDiff-Evolved
- **接入方式**：作为ComfyUI节点或Automatic1111扩展
- **适用场景**：角色动画、场景动态化

### 3. WAN 2.2
- **来源**：阿里开源
- **类型**：多模态视频生成模型
- **能力**：
  - T2V/I2V/F2LF（首尾帧）多模式
  - Lightx2v LoRAs + RIFE插值，超流畅5秒视频
  - ComfyUI工作流：SmoothMix WAN 2.2 v5.0
- **接入方式**：ComfyUI节点
- **适用场景**：电影感短片、流畅动画

### 4. FLUX 3 Video
- **来源**：Black Forest Labs
- **类型**：原生音频同步视频生成
- **能力**：
  - 单文本提示生成完整视频，含同步音频、运动、物理
  - 不需要参考图或复杂设置
  - 支持T2V和I2V
- **接入方式**：ComfyUI Partner Nodes
- **适用场景**：快速出片、音频同步

### 5. HappyHorse 1.1
- **来源**：ComfyUI生态
- **类型**：多角色舞台视频生成
- **能力**：
  - T2V：完整场景，控制风格、镜头、灯光、动作、音频
  - I2V：静态首帧动画化
  - R2V：多角色舞台编排，映射角色和场景到参考图
- **接入方式**：ComfyUI节点
- **适用场景**：多角色对话、剧情片

## 二、数字人/唇形同步框架

### 1. SadTalker（开源标杆）
- **来源**：https://sadtalker.ai/ ｜ GitHub: OpenTalker/SadTalker
- **论文**：CVPR 2023，西安交大+腾讯AI Lab+蚂蚁集团
- **类型**：单图音频驱动说话头生成
- **能力**：
  - 单张人像+音频 → 真实说话头视频
  - 3DMM系数中间表示，不是直接生成像素
  - 完美唇形同步、自然眨眼、头部姿势控制
  - 支持Gradio WebUI和无头CLI批量处理
- **硬件要求**：4GB VRAM最低
- **接入方式**：
  - 本地部署：`python app_sadtalker.py`
  - Automatic1111扩展
  - ComfyUI自定义节点
- **为什么选它**：开源数字人黄金标准，无水印，零成本，本地运行

### 2. MuseTalk（实时唇形同步）
- **来源**：腾讯Lyra Lab开源 ｜ GitHub: TMElyralab/MuseTalk
- **论文**：MuseTalk: Real-Time High Quality Lip Synchronization with Latent Space Inpainting
- **类型**：实时唇形同步（非扩散模型）
- **能力**：
  - 潜在空间修复，单步生成，30fps+（V100）
  - 256×256面部区域，保留身份和纹理
  - 支持中文、英文等多语言音频
  - 最新版本v1.5（2025-03-28），perceptual+GAN+sync损失
  - 端到端延迟0.17s，141 FPS（A10）
- **接入方式**：
  - 本地部署，API调用
  - LiveTalking-v15已集成MuseTalk v1.5
- **为什么选它**：实时性最好，适合直播、实时对话场景

### 3. LivePortrait（新一代标杆）
- **来源**：开源
- **类型**：视频驱动的人像动画
- **能力**：
  - Video-to-Video驱动：录自己说话，AI把表情/眨眼/头部倾斜映射到任何静态照片
  - 无水印，零成本
  - 比SadTalker更自然的表情迁移
- **接入方式**：本地部署
- **为什么选它**：表情迁移最自然，适合"用自己的表情驱动数字人"

### 4. Live Avatar（阿里开源）
- **来源**：阿里开源
- **类型**：实时数字人
- **能力指标**：
  - Dino-S身份一致性：0.921（领先LivePortrait的0.843）
  - Sync-C口型同步：0.982（领先）
  - ASE美学评分：7.8（领先）
- **接入方式**：本地部署
- **适用场景**：高保真数字人直播

### 5. Wav2Lip（轻量级）
- **来源**：开源
- **类型**：轻量级唇形同步
- **能力**：
  - 最轻量，最易集成
  - 适合资源受限场景
- **接入方式**：本地部署，API调用
- **适用场景**：快速集成、低资源环境

### 6. LiveTalking-v15（集成方案）
- **来源**：Gitee: brucezhao/LiveTalking-v15
- **类型**：实时流式数字人（基于NeRF）
- **能力**：
  - 集成MuseTalk v1.5
  - 本地语音识别（vosk）
  - 接入Coze工作流
  - 对话记录功能
  - HTTPS支持
- **接入方式**：本地部署，Web界面
- **适用场景**：完整的数字人对话系统

## 三、工作流自动化

### ComfyUI自动化管线
- **来源**：https://thecascadehub.com/automating-video-workflows-with-comfyui/
- **能力**：
  - 手动生成 → 自动化管线，睡觉时跑
  - 文本提示 → 批量处理视频帧
  - 支持数百张图片的动画序列处理
- **接入方式**：ComfyUI API + 脚本调度
- **为什么重要**：我们的视频组是"智能体跑一次出一个片"，应该是"工作流自动跑批量出片"

## 四、接入建议（按优先级）

### P0：先接ComfyUI
- 理由：所有视频生成模型的统一入口，工作流可复用
- 动作：本地部署ComfyUI，把现有视频生成改成调用ComfyUI工作流
- 预期效果：视频生成从"线性不可控"变成"节点式可视化可复用"

### P1：接SadTalker + MuseTalk
- 理由：数字人真人感的核心，解决"全是陈述、没有真人感"的问题
- 动作：部署SadTalker做数字人视频，MuseTalk做实时唇形同步
- 预期效果：数字人从"纸片人"变成"会说话、有表情"

### P2：接LivePortrait
- 理由：表情迁移最自然，用老板自己的表情驱动瞳瞳
- 动作：部署LivePortrait，录老板说话视频，驱动瞳瞳角色
- 预期效果：瞳瞳的表情=老板的表情，真人感拉满

### P3：工作流自动化
- 理由：从"智能体手动跑"变成"工作流自动批量跑"
- 动作：用ComfyUI API + 调度脚本，批量生成视频
- 预期效果：出片效率提升10倍，成本降低
